Цей проєкт є простим Node.js веб-застосунком (app.js), контейнеризованим за допомогою Docker, який запускає HTTP-сервер і відображає значення змінних середовища STUDENT_NAME, GROUP та MODE; у межах роботи було створено Dockerfile, зібрано Docker-образ, запущено контейнер із налаштуванням портів, змінних середовища та мережі Docker, що демонструє базові принципи контейнеризації та ізоляції застосунків.
